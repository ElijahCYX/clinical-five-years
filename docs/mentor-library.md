## 处理规则（后续扩充直接沿用）

1. 学者名一律化名：更换姓氏 + 部分名字谐音处理；游戏内不保存真名。
2. 院系只使用「医学院」或「基础医学院」。
3. 职务只能从以下四组中选一个：
   - 1：特聘教授 / 教授 / 副教授
   - 2：博士生导师 / 硕士生导师
   - 3：主任医师 / 副主任医师
   - 4：特聘研究员 / 研究员 / 副研究员
4. 基础医学院不能出现主任医师 / 副主任医师。
5. 教授与研究员不能同时出现在同一人身上。
6. 只有基础医学院允许研究员类型职务。
7. 代表期刊按影响因子/权威性取 5 个；成果特别多时可扩到 10 个。
8. 找得到信息就按信息填写；找不到时再随机，但必须满足以上院系与职称约束。
9. 游戏数据只保留：化名、院系、职务、研究方向、导师等级、代表期刊、隐藏面板属性。
10. 下次扩充学者库时，直接按本规则处理新名单，不再重复确认规则。

## 化名审计

- 第一版：保留原姓或原名，容易直接认出原型。
- 第二版：完全随机姓名，念出来也无法联想到原型。
- 当前版：采用“同音异字”方案，保留名字的读音线索，但字形全部替换。
  - 换姓：用同音或近音姓氏。
  - 换名：用同音或近音字，尽量不保留原字。
  - 第一眼看是另一个名字，念出来才接近原型的读音。
