# 临床五年 · 可玩初稿

一个医学本科生五年生活文字模拟器的网页版可玩初稿。

**在线访问：** https://elijahcyx.github.io/clinical-five-years/  
**仓库：** https://github.com/ElijahCYX/clinical-five-years

推送到 `main` 后，GitHub Actions 会自动构建并部署到 GitHub Pages。

当前版本可以完整游玩 **大一到大五**：

> 新生报到 → 大一（秋/冬/寒假/春/夏/暑假）→ 大二（秋/冬/寒假/春/夏/暑假）→ 大三（秋/冬/寒假/春/临床前学期）→ 大四（秋/冬/春/夏，无假期）→ 大五（秋/冬/春/夏，无假期）→ 毕业 / 延毕

事件、人物关系、科研与完整毕业结局会按同一套接口继续接入。

## 运行

```bash
npm install
npm run dev
# 打开 http://127.0.0.1:5173/
```

让同一 Wi-Fi 下的手机 / 平板访问：

```bash
npm run dev:lan
# 打开 http://<本机局域网 IP>:5174/
```

本机当前局域网地址是 `192.168.10.104`，对应 `http://192.168.10.104:5174/`。
如果手机打不开，请在 macOS 防火墙提示里允许 node 接收传入连接。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现

- **选修课**：大一至大三每学期计划前展示四类课程各一门（水课/兴趣课/小组作业课/思政课），每类下方可无限刷新查看全库；可报 0–3 门，水课 50%、兴趣课 25%、小组作业课 75%、思政课 100%；水课准备度收益高，兴趣课每周 -5 压力 / +5 精力且给分好，小组作业课每周 -5 精力并增加人际；第一周可退选，水课/兴趣课挂科可放弃，小组作业/思政挂科自动重修；选修毕业最多计入 10 学分
- **思政必修**：马原 3 / 毛概 3 / 思修 2 / 军理 2 / 形势与政策 1，共 11 学分，作为 100% 选中的选修课在大一至大三期间完成；毕业总学分 163 专业课 + 11 思政 + 10 选修 = 184
- **对自己好一点！**：周行动，精力 +25、压力 -15、生活费 -100、体质成长 -5；生活费不足时不可选
- **舍友与关系**：每次新建角色生成 3 名同性别舍友和辅导员/导师；舍友每周有随机行动；亲密度 0–100，初始由建模/交际决定；面板数值默认隐藏，亲密度提升或事件刷新时以快照形式揭示，100 时完全解锁
- **关系性别与亲密度底色**：TA 列表与舍友卡片的人名后显示 ♂/♀；人名框背景随亲密度提高而略微加深
- **拍一拍加成**：同学 20% 借笔记（随机在修课程准备度 +5）、10% 请奶茶/吃饭（压力 -5、精力 +5）；导师 25% 科研进度 +2；辅导员 25% 谈心（压力 -5）
- **待办角标**：主界面有剩余行动时显示剩余次数；TA 页有未使用拍一拍时显示剩余次数；完成决策后角标自动消失
- **TA 是谁**：主界面/我是谁/TA 是谁三栏切换；关系页可查看姓名、身份、亲密度，并可每周对每人拍一拍（+2 亲密度，不占行动）；每人每周一次，全周最多拍 3 次；顶部剩余次数按钮可点击，自动拍亲密度最高的前三位；支持按「长辈（导师/辅导员）」与「同辈」筛选
- **朋友聚餐**：点击「和朋友吃饭」选择朋友，按亲密度分别判定是否应邀；基础生活费 50，每多一人赴约减 5（2 人 50 / 3 人 45 / 4 人 40）；不再增加综测，赴约者分配总共 6 点亲密度（1 人 +6、2 人各 +3、3 人各 +2、4 人各 +1）
- **表白与多线恋爱**：亲密度 >60 且玩家性别/性取向允许时可表白；成功率由对方性取向、亲密度、交际面板决定，不占行动；可以同时与多人建立恋爱关系，但每多维持一周会累积被发现风险，被发现后所有恋爱关系破裂、交际 -3、压力 +10
- **前任复合窗口**：分手后有 3 周复合窗口，每周按当前亲密度计算复合概率，并从第 2 周起每周最终概率 -10 个百分点；3 周后再次表白（无论方向）成功概率 -50%，NPC 主动表白触发概率也减半
- **NPC 主动关系事件**：亲密度 ≥60 时，NPC 可能反向表白，玩家可选择接受或婉拒；亲密度 <60 的恋人会累积分手风险；导师/辅导员表白与被表白概率都显著降低，师生恋每周累积被发现风险，被发现后关系破裂、交际 -2、压力 +8
- **习惯调整**：看文献在进组前不加科研，改为导师亲密度 +2；每周家人电话压力 -3、家人好感 +5；早睡压力 -2；冥想/散步压力 -3，并可能触发偶遇
- **家人好感**：家人好感 ≥20 后每周有概率触发「朝廷赈灾粮来了」，家长额外打 500 生活费
- **偶遇聊天库**：冥想/散步可能偶遇新人或已认识的同学；共享 30 组聊天、每组 3 个回复选项，选择前隐藏后果，选择后显示亲密度 -5~+5
- **实验室打杂**：精力消耗 -7～-13（悟性越高越低），导师亲密度 +5；打杂期间每周有额外 10% 概率收到导师分配课题通知，接取后加成自然撤除
- **科研课题与 Hypothesis**：导师初始亲密度由悟性/交际 3:1 决定（0–40），不参考建模；亲密度 40 解锁实验室，60 触发「开始课题」并抽取导师的 Hypothesis；每学期秋导师会发新 idea，可接/不接；接项目后超过 3 周不选科研行动会收到导师警告，扣亲密度、涨压力；科研行动会根据阶段改名为科研相关 / 实验室打杂 / 开题设计 / 实验推进 / 论文撰写 / 投稿发表
- **科研突发事件**：临时组会、导师电话、仪器故障、同门帮忙、论文返修、组会汇报等
- **科研系统**：随机事件结识导师后解锁；导师亲密度达到 60 会通知进组；进组后解锁科研行动，每次随机 +1–5 科研进度（悟性越高越容易高值）；进度阶段为开题设计 / 实验推进 / 论文撰写 / 投稿发表，100 分时弹出论文发表通知并按导师等级随机期刊
- **随机事件**：每周行动前判定；先掷 5% 命中完全随机库（110 条，含新增社交事件）并等概率抽取，否则判定场景触发（40 条，20%），仍未触发再判定属性触发（40 条，15%）；每周最多 1 条，同一条不重复；社交/恋爱事件中的学弟/学妹/学长/学姐会按玩家性别与性取向生成；事件库总计 190 条
- **属性触发**：建模、交际、体质、精力、压力、综测、科研、英语、GPA、挂科记录等都会解锁对应事件；例如建模 ≥ 8 会触发被要微信，交际高则加微信并解锁社交模块占位，交际低则压力 +5
- **性取向**：新生报到可选异性恋 / 同性恋 / 双性恋，影响社交、恋爱类事件中 NPC 的性别与称呼
- **姓名库**：100 个姓 × 1000 个名（100 个一字名 + 900 个二字名）随机组合成 2–4 字姓名；新生报到点「随机生成」时同时随机姓名、性别和家庭背景
- **新生报到**：4 档资质（平庸 35 / 出色 45 / 精英 55 / 天才 65）、8 维属性自由分配（每项 2–10）、姓名 / 性别 / 家庭背景；入学时结算并固定「档案称号」，之后属性成长不会改名
- **入学档案称号**：单项属性突出时有专属称号（如高精力人群、黑/白皮体育生、被医学耽误的模特），相近的两项组合有双属性称号，全部接近则“六边形新兵”
- **学期计划**：开学先展示本学期课程、学分、考试类型和难度星级（按学分/考试类型/记忆与悟性估算），再选择 A 稳扎稳打 / B 周期回顾 / C 考前突击；每学期选 2 个养成习惯，两个习惯同时生效；压力 > 60 时习惯失效
- **生活费**：一季 = 四周 ≈ 一个月；平民 / 小康 / 中产 / 名门每月生活费 1500 / 2000 / 2500 / 3000，学期内每周固定开销 300，假期在家不扣固定开销；每个新学期发一次月度生活费
- **开局天赋**：领取学生证后进入天赋阶段；平庸资质只能看不能选；普通资质三选一、每卡刷新一次；天才资质三选二、每卡刷新两次。12 个天赋全部实装：洋腔洋调、医学世家、高压锅体质、高精力牛马、建模怪、咖啡因免疫、考前突击王、社交悍匪、手稳心细、记忆面包、上岸上岸、菜菜捞捞
- **界面主题**：压力 >79 时全局转向红色警示主题并带暗角呼吸；精力 <20 时转向蓝色低电量主题；两者同时触发时混成暗紫灰
- **界面动效**：面板/弹窗入场、卡片悬浮、按钮按压、标签页下划线动画，并支持系统减少动态效果
- **移动端布局**：窄屏下主界面隐藏左右侧栏，改用顶部状态 HUD + 单列行动卡；考试/计划/成绩等页面同步收窄间距，版本号移出固定悬浮层，改为页面底部显示
- **双界面导航**：周循环为主界面，底部居中可切换到「我是谁」玩家简历；简历汇总面板属性、成绩、CET、体育、奖学金、学年记录与毕业去向
- **统一左侧栏**：学期周循环和考试周共用同一列「人物档案 / 状态 / 计划」，精力与压力采用和准备度一致的行内进度条
- **小组作业 / 选修课程**：本学期有选修时可选，非思政选修准备度 +20、思政选修 +15，精力 -8 / 压力 +3；没有选修课时灰显
- **周循环**：每学期 3 个行动周 + 1 个考前复习周；每周选择 2 个行动；每周「学英语」行动英语进度 +4~+6，按记忆力微调；多课程时点击泡图书馆会先弹出「本周主攻」——主课程只能选必修课，不能选选修/思政；主课程拿 75% 准备度收益，其余课程平分 25%，也可全部均衡；泡图书馆每门课准备度 +6×K，精力/压力成本随同时在修课程数增加（1 门 -10/+10、2 门 -15/+15、3 门 -20/+20，超过 3 门不再增加），并受精力/抗压面板系数影响；可重复选两次
- **考前复习**：均衡复习精力 -20；历年卷 + zsy 笔记收益等同均衡复习、临场波动更小，但卷面成绩上限 95；主攻单门精力 -20
- **选择预览**：选行动时显示结算后的精力 / 压力 / 生活费 / 综测 / 英语 / 科研 / 各科准备度；进度条中较浅或斜线部分表示尚未发生的预计变化，正式结算前会再确认
- **行动**：泡图书馆、科研、社团、休息、社交、兼职、运动、英语等；部分行动有前置条件；纯粹的休息为精力 +20 / 压力 -15；运动为精力 +10 / 压力 -5
- **体质成长**：健身习惯 +18 / 周；每周运动 +42；体质 5 的玩家只靠健身一学年到 8，只靠每周运动一学年到 10
- **考试**：课程难度（记忆力/悟性 低/中/高）→ K 匹配系数 → 每周被动准备度 → 考前复习 → 卷面分 → 5 分制绩点；考试周只能单独复习必修课和思政课；其他选修课不参与考试复习且不获得任何准备度收益；可主攻任意一门必修/思政 / 均衡 / 历年卷+zsy 笔记 / 休息；全力复习精力 -20、压力 +10；历年卷精力 -10、压力 +5；休息精力 +20、压力 +5
- **考试周状态**：考前复习页右侧显示精力 / 压力 / 生活费 / 综合测评 / 英语 / 科研，以及计划和习惯；加餐使用后数值立即更新
- **考试周额外操作（不占行动次数、不可撤销）**：喝咖啡（生活费 -50、精力 +10、压力 +5、准备度收益 +15%，每场限一次；咖啡因免疫时压力副作用为0）；刷夜（精力 -10、体质成长 -10、压力 +10、所有课程准备度 +15，但本次成绩下调 5%，每场限一次）；英语备考见上
- **四六级事件**：每学年两次——冬学期大考前、夏学期大考前报名；报名费 50；冬季考试春季出成绩，夏季考试秋季出成绩。CET-4 / CET-6 总分 750、通过线 425，CET-4 成绩下限 200、CET-6 成绩下限 150；英语进度 ≥25 / ≥60 / ≥100 分别保证 CET-4 425、CET-6 425、CET-6 550；CET-6 ≥ 550 才算毕业英语合格。CET-4 通过后不能重考；CET-6 通过后仍可继续报名刷分，成绩取历史最高
- **英语备考**：大考周加餐之一，精力 -10 / 压力 +5 / 英语进度 +5；当季有 CET 报名时，给该次 CET 增加 10% 通过概率（仅当次有效，不结转）；本次考试周复习收益 -10%
- **大一全流程**：秋（大学数学）→ 冬（有机化学 + 普通化学）→ 寒假 → 春（系统解剖学）→ 夏（生物化学 + 病原微生物）→ 暑假 → 大一学年结算
- **大二**：生理学 + 医学免疫学 → 病理学 + 药理学 → 寒假 → 病理生理学 + 医学统计学 → 预防医学 + 医学心理学 → 暑假 → 大二学年结算
- **大三**：外科学总论 + 医学影像学 → 诊断学 → 寒假 → 临床药理学 + 循证医学 → 临床前学期（临床前综合考核，5 学分）→ 大三学年结算；大三夏天会被临床前学期替代，没有暑假
- **大四**：内科见习 / 外科见习 / 妇产见习 / 儿科见习 + 麻醉、急诊、皮肤、全科、精神轮转；大四春选择毕业去向（保研 / 双线 / 就业）；无假期，夏学期仍有四六级机会
- **大五**：内外妇儿实习 + 眼科、耳鼻喉、康复、社区、医患沟通；大五秋公布推免结果，大五冬考研初试，大五春考研结果；无假期，夏学期仍有四六级机会
- **学分**：专业课 163（前三年 83 + 临床两年 70 + 体育 10）+ 思政 11 + 选修 10 = **184**；体育成绩按体质结算，体育共 5 门（每门 2 学分）；选修课毕业只计前 10 学分
- **补考**：挂科课程会在下一学期周循环和考试周作为“补考”课程出现；补考通过后按原绩点与补考绩点平均、向下取整到 1 位小数，学分只算一次
- **毕业条件**：184 学分（其中选修课 ≥10）、CET-6 ≥ 550、补考全部通过、体育毕业补考通过；显示毕业或延毕，完整结局后续接入
- **体质衰退**：没有选择「健身」习惯，且本周行动没有选择「运动」时，每周体质成长 -5（降到 0 为止）；周行动页会显示提醒
- **压力/精力状态**：压力 >60 习惯失效；>70 考试准备度收益 -10%；>80 触发高压事件并挂上 -30% 备考收益 debuff，压力 <60 后解除。精力 <60 时所有精力消耗 +10%，<40 时 +20%，<20 时 +40% 并触发低精力事件；付不起的行动灰度不可选。精力/压力条会按绿/橙/红/黑变色
- **出成绩降压**：每门课程出分后按预计区间折算压力奖励，最高 -10；预计 80–90 时考 80 为 0、考 90 为 -10；每门课程只结算一次，成绩单会显示单科降压和总降压
- **假期**：大一、大二有寒假 2 周和暑假 3 周；大三只有寒假，夏季进入临床前学期；假期没有考试、不选学习计划，但习惯继续生效
- **假期行动**：回家（精力 +10 / 压力 -10 / 生活费 -50）；旅行（精力 -5 / 压力 -30 / 生活费 -500）；社会实践（综测 +6 / 精力 -15 / 压力 +5）；健身（体质成长 +10 / 精力 -5 / 压力 -10）；学英语（英语 +5 / 精力 -10 / 压力 +5）；休息（精力 +20 / 压力 -20）；娱乐（精力 +10 / 压力 -15 / 生活费 -100）；约朋友耍起（人际成长 +20 / 精力 -5 / 压力 -15 / 生活费 -200）；实验室牛马（科研 +10 / 精力 -10 / 压力 +10，需已选导师并进入实验室，当前灰色占位）
