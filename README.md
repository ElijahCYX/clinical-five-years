# 临床五年 · 可玩初稿

一个医学本科生五年生活文字模拟器的网页版可玩初稿。

**在线访问：** https://elijahcyx.github.io/clinical-five-years/  
**仓库：** https://github.com/ElijahCYX/clinical-five-years

推送到 `main` 后，GitHub Actions 会自动构建并部署到 GitHub Pages。

当前版本可以完整游玩 **大一整年**：

> 新生报到 → 大一秋 → 大一冬 → 寒假 → 大一春 → 大一夏（四六级报名）→ 暑假 → 四六级成绩公布 → 大一学年结束

大二、临床年、事件、人物关系、科研与奖学金会按同一套接口继续接入。

## 运行

```bash
npm install
npm run dev
# 打开 http://127.0.0.1:5173/
```

让同一 Wi-Fi 下的手机 / 平板访问：

```bash
npm run dev:lan
# 打开 http://<本机局域网 IP>:5174/
```

本机当前局域网地址是 `192.168.10.104`，对应 `http://192.168.10.104:5174/`。
如果手机打不开，请在 macOS 防火墙提示里允许 node 接收传入连接。

生产构建：

```bash
npm run build
npm run preview
```

## 临时公网测试

项目是纯静态页面，部署方式很简单。当前用 `localhost.run` 的临时 SSH 隧道给朋友测试：

```bash
# 1. 构建并用静态服务器托管 dist
npm run build
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist

# 2. 另开一个终端，建一条临时公网隧道
ssh -R 80:localhost:4173 nokey@localhost.run
# 终端会打印 https://xxxx.lhr.life 形式的公网地址
```

缺点：Mac 要一直醒着、终端不能关，SSH 断开后地址会变；出现页面时可能需要点一次 Continue。

要长期稳定访问，建议部署到 GitHub Pages、Cloudflare Pages、Vercel 或 Netlify。
这些都只需要一个免费账号；需要的话我可以直接把 `dist/` 部署上去。

## 已实现

- **新生报到**：4 档天赋（平庸 35 / 出色 45 / 精英 55 / 天才 65）、8 维属性自由分配（每项 2–10）、姓名 / 性别 / 家庭背景
- **入学档案称号**：单项属性突出时有专属称号（如高精力人群、黑/白皮体育生、被医学耽误的模特），相近的两项组合有双属性称号，全部接近则“六边形新兵”
- **学期计划**：A 稳扎稳打 / B 周期回顾 / C 考前突击；11 个养成习惯卡片；习惯数值已整体下调为潜移默化的小幅修正；压力 > 60 时习惯失效
- **生活费**：一季 = 四周 ≈ 一个月；平民 / 小康 / 中产 / 名门每月生活费 1500 / 2000 / 2500 / 3000，每周固定开销 250；每个新学期发一次月度生活费
- **统一左侧栏**：学期周循环和考试周共用同一列「人物档案 / 状态 / 计划」，精力与压力采用和准备度一致的行内进度条
- **周循环**：每学期 3 个行动周 + 1 个考前复习周；每周选择 2 个行动；泡图书馆（精力 -10 / 压力 +10）可重复选两次
- **选择预览**：选行动时显示结算后的精力 / 压力 / 生活费 / 综测 / 英语 / 科研 / 各科准备度；进度条中较浅或斜线部分表示尚未发生的预计变化，正式结算前会再确认
- **行动**：泡图书馆、科研、社团、休息、社交、兼职、运动、英语等；部分行动有前置条件
- **考试**：课程难度（记忆力/悟性 低/中/高）→ K 匹配系数 → 每周被动准备度 → 考前复习 → 卷面分 → 5 分制绩点；大考支持两门课，复习时可主攻 / 均衡 / 历年卷+zsy 笔记 / 休息；全力复习精力 -20、压力 +10；历年卷精力 -10、压力 +5；休息精力 +20、压力 +5
- **考试周状态**：考前复习页右侧显示精力 / 压力 / 生活费 / 综合测评 / 英语 / 科研，以及计划和习惯；加餐使用后数值立即更新
- **考试周额外操作（不占行动次数、不可撤销）**：喝咖啡（生活费 -10、精力 +10、压力 +2，每场限一次）；刷夜（精力 -10、体质成长 -10、压力 +10、所有课程准备度 +15，但本次成绩下调 5%，每场限一次）
- **四六级事件**：大一夏第 3 周（考试周前一周）弹出报名；CET-4 / CET-6 总分 750、通过线 425，CET-6 ≥ 550 才算毕业英语合格；成绩按英语进度和记忆力赋分，英语 40/75/100 分别保证 CET-4 425 / CET-6 425 / CET-6 550 的下限；成绩在大二秋开学前公布
- **大一全流程**：秋（大学数学）→ 冬（有机化学 + 普通化学）→ 寒假 → 春（系统解剖学）→ 夏（生物化学 + 病原微生物）→ 暑假 → 大一学年结算
- **假期**：寒假 2 周、暑假 3 周；没有考试、不选学习计划，但习惯继续生效
- **成绩单**：多科成绩、学期 GPA、累计 GPA、已修学分、导员评语
- **存档**：localStorage 自动保存 / 手动保存 / 标题页继续
- **响应式**：桌面三栏（人物 / 本周安排 / 手记），手机单栏
- **UI 预览路由**（不改存档，直接看各界面）：
  - `?demo=title`
  - `?demo=create`
  - `?demo=plan`
  - `?demo=week`
  - `?demo=prep`
  - `?demo=result`
  - `?demo=vacation`
  - `?demo=cetEvent`
  - `?demo=cetResult`
  - `?demo=yearend`
  - `?demo=ending`

CET-4 / CET-6 的跨年重考、雅思 / 托福事件、以及把 CET-6 ≥ 550 接入毕业判定，也会在后续年份接入。当前刷夜的“体质 -10”按面板 2–10 体质属性对应的成长进度扣除，如果你想要独立的 0–100 体力条，可以下一轮拆出来。

## 项目结构

```
src/
  types.ts        类型定义
  data.ts         属性、天赋、家庭背景、计划、习惯、行动、课程
  game.ts         K 系数、准备度、卷面分、绩点等核心公式
  demo.ts         截图用演示状态
  ui.tsx          共享组件（顶栏、印章、进度条、线稿等）
  screens/        标题 / 新生报到 / 学期计划 / 周循环 / 考前复习 / 成绩单 / 假期 / 四六级 / 结局
  App.tsx         真实游戏流程 + demo 路由
  styles.css      视觉系统（纸张、墨绿、衬线、印章）
shots/            UI 截图
scripts/          Playwright 本地截图与流程检查脚本
```

## 说明

- 标题《临床五年》、校名“临江大学医学院”均为工作用占位，可在 `src/data.ts` 中替换。
- 角色姓名、学校、医院、人物均为虚构；游戏不构成医学建议。
- 当前为 UI 与系统初稿，数值平衡、事件文案与医学内容仍需后续迭代。
